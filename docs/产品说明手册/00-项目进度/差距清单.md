# 差距清单

分为两类：**功能差距（G）**，即需求要求但尚未实现的能力；**缺陷与技术债（D）**，即已有代码中的问题。优先级：P0 = 阻塞 L3 Alpha；P1 = 阻塞 L4 Beta；P2 = 阻塞 L5 / L6。工作量以「人周」估算。

> 本表只保留当前尚未完成的差距；已经交付的浏览器工具、模型审计和安全恢复能力不再作为差距列出。人周与合计沿用历史规划估算，未重新计算剩余工作量。
