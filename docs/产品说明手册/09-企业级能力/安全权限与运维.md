# Agent 执行安全与部署边界

> 定位更新：2026-10-07。沿用原文件路径以保持引用有效；本文只定义 GUI 检测—修复平台中 Agent 组件的安全与运维要求。

## 1. 职责划分

| 范围 | 上层 GUI 平台 / 部署方 | TraceFix Agent 组件 |
|---|---|---|
| 调用认证 | 服务入口认证、用户身份和用户权限校验 | 受控地址与服务 token 边界；校验传入任务及资源归属 |
| 任务控制 | 排队、选择 Finding、审批、通知和补丁发布 | 单 Run 执行、状态 / 事件 / 结果查询、取消与有界恢复 |
| 数据 | 平台用户数据、保留策略与备份 | 源码版本、规则快照、Run 事件、回执、diff 和证据 |
| 执行环境 | 提供受审 Profile、镜像、模型 / MCP 服务与凭据引用 | 工作区、路径、网络和工具权限校验，独立验证与产物脱敏 |

TraceFix 不建设用户账户、组织成员、角色管理、多租户、计费、集中管理后台或分布式运维平台。上层平台已经授权任务，也不能绕过 Agent 的路径、工具、证据和验证门。

## 2. 已有执行保护

| 能力 | 实现依据 | 边界 |
|---|---|---|
| 沙箱与网络 | `execution/runner.py`、`execution/policy.py` | Run 专属 internal 网络、资源与容器权限限制；只用于受控测试项目，不承诺可安全执行任意恶意仓库 |
| 文件与补丁 | `execution/workspace.py`、`runtime/local_tools.py` | 路径、符号链接、受保护文件、before_hash / patch hash 校验；Bash 在授权 Docker 副本执行 |
| 工具与状态 | `runtime/tools.py`、`runtime/tool_handlers.py`、`runtime/engine.py` | 模型只能提议；运行时检查阶段、授权范围、操作账本和验证门 |
| 幂等与恢复 | `storage/store.py`、`storage/checkpoints.py` | intent / receipt 与 checkpoint；结果未知时保留核查要求，不盲目重放 |
| 证据与审计 | `storage/artifacts.py`、`storage/presentation.py` | 记录 Run、源码、规范和补丁绑定，验证完整性；脱敏能力有适用范围 |
| 服务入口 | `backend/apps/console-api/server/index.mjs` | 已有 loopback / `TRACEFIX_CONTROL_TOKEN`、Host / Origin 校验；不等同于完整任务型 API 已交付 |

现有单进程 Worker 调度用于 Agent 内部子任务，不承担平台级任务队列或跨实例故障接管。具体真实运行和测试结论见[完成度评估](../00-项目进度/完成度评估.md)，不沿用旧测试数宣称当前全量通过。

## 3. 对外接口的必留约束

- 部署入口只接受受信任的平台服务调用；非本机访问配置服务 token 或由可信网关注入认证，凭据不进入模型上下文、日志和报告。
- 每次读写校验仓库 / 项目、Run、源码 revision、规则快照和产物归属；路径与证据引用不能指向别的任务。
- 提交幂等、繁忙拒绝、按 Run 取消、断连和重启后的状态查询采用稳定语义；未知操作不标为安全可重试。尚未补齐的部分按接口型 Beta 工作包验收。
- 修复成功必须有当前补丁的原问题、逆向 / 刷新 / 正常业务回归及工程验证；未覆盖、未复现、未验证和基础设施故障分别报告。
- 候选 diff 与验证证据返回上层平台；应用补丁、Git 提交、push / PR 和发布由平台流程处理。现有本地交互提交仍须显式审批。
- 私有截图、测试账号和源码只在授权范围内处理；未实现脱敏适配的场景应明确拒绝或返回限制说明。

## 4. 组件运行与排障

部署方准备 Node、Python、PostgreSQL、Docker、Playwright MCP 和模型服务，按实际依赖区分存活与就绪。首版采用受信任单实例，外部排队；不依赖新建集群、Helm 或集中告警看板。

Run 级结构化事件、模型 / 工具错误、用量、阶段耗时和 artifact 引用供上层平台采集。基础设施异常要保留 request / Run 标识、错误类别与核查要求，不能泄露密钥或将状态未知改为成功。

验收覆盖认证拒绝、跨仓库 / Run 拒绝、凭据脱敏、重复提交 / 取消、UNKNOWN、无进展收敛、产物完整性及一个真实业务闭环；开发过程只跑相关定向检查，最终集成完成后只跑一次完整基线。详见[接口型 Beta 计划](../00-项目进度/接口型Beta最小补足与开发计划.md)。
