# RL / MARL 文献与实验研究记录

调研日期：2026-10-04（Asia/Shanghai）。主要时间窗：2025-10-04 至 2026-10-04。

## 工作步骤

1. 核查官方论文集、期刊页面与论文正文，建立创新点表。
2. 检查相邻工作，将可组合机制收敛为五个研究假设。
3. 按用户提供的应用、算力与时间预算设计公平的小批次实验。
4. 顺序验证，保存配置、随机种子、原始结果、消融与失败案例。
5. 每完成一个验证，使用 ICASSP 格式撰写与实际证据一致的英文初稿。

## 证据规则

- 预印本不自动视作顶会或顶刊论文；正式接收必须有官方来源。
- 首次 arXiv 日期、接收日期、会议日期和期刊出版日期分别记录。
- 小样本结果只支持可行性判断，不声称已证明领先性能或投稿就绪。
- 组合机制首先检查是否已有等价工作；来源方法没有完整复现时不使用其名称冒充基线。
- 训练、调参、最终评估采用不同随机种子；完整实验基线仅在本轮开发完成后运行一次。

## 文件

- `collect_sources.py`：保存公开官方来源、检索标题和下载正文；使用 Python 标准库。
- `sources/`：带 URL、抓取时间与 SHA-256 的证据记录。
- `cache/`：下载的 HTML/PDF，仅在本地保留，不提交第三方论文全文。
