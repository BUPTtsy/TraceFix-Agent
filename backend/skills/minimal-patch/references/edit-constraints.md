# 编辑纠错表

## 宿主拒绝候选（原因原文 → 处理）
| 原因 | 处理 |
|---|---|
| 不允许删除或重命名 | 恢复原文件，只改内容 |
| 不允许冻结测试或保护文件变化 | 还原测试与保护文件，改被测源码 |
| SDK 候选越过当前增量文件授权 | 还原 writable_files 以外的文件 |
| 不允许隐藏路径变化 | 不写点文件或点目录 |
| 空目录、可执行文件、链接、类型或模式变化 | 不 mkdir 空目录，不 chmod，不建链接 |
| 只允许 UTF-8 普通文本 / 二进制内容 | 保持 UTF-8 文本 |
| 不允许空内容 | 不清空文件 |
| 候选包含受保护凭据 | 删掉写入的密钥值 |

## Edit 失败
- old_string 不唯一：加相邻行使其唯一，不用 replace_all 批量改。
- 找不到 old_string：重新 Read，以当前内容为准，不凭记忆。
- 改后语法或类型错误：读报错行，在同一处修正。

## 反模式 → 纠正
| 反模式 | 纠正 |
|---|---|
| 改测试或断言让它通过 | 改被测源码 |
| 用 ??、try/catch、默认值吞错误 | 修产生错误值的源头 |
| 顺手重构、格式化、改名 | 只保留根因所需的行 |
| 凭文件名或报错文字猜根因 | Read 调用链直到写入点 |
| 多个假设一起改 | 只改证据支持的那一个 |
| 自测通过就写"已修复" | 写"待宿主验收" |
